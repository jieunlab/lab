# Jung Lab website

A responsive, static research group website for GitHub Pages.

## Deploy
1. Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository.
2. Open **Settings → Pages** and choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
3. If your repository is named `jieunlab.com`, the default URL is `https://jieunlab.github.io/jieunlab.com/`.
4. If renamed to `jieunlab.github.io`, the default URL is `https://jieunlab.github.io/`.
5. To use `jieunlab.com` as a custom domain, first register it and then configure GitHub Pages custom domain and DNS records.

## Before publishing
- Replace the placeholder Publications section with verified papers and DOI links.
- Add a public lab email and confirmed office details.
- Add approved lab photographs and member profiles.
- Review all scientific descriptions and the news entry.

Navigation: TOP, Research, Members, Publications, Facilities, News, Contact.
